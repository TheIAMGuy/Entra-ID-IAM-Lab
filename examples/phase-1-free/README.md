# Phase 1 — Free Tier Examples

Working examples from **Lab 01–03**: Environment Setup, Identity Provisioning, and Group-Based RBAC.

## Files

- `users-example.json` — User objects created in Lab 02 (Joiner scenario)
- `groups-example.json` — Groups created in Lab 03 (department groups)
- `rbac-assignments-example.json` — Role assignments for Lab 04 (User Admin, Global Reader)

## How to Use

1. Review the exported JSON structure
2. Adapt the groups and users to your environment
3. Import via Microsoft Graph or recreate in the Entra ID admin center
4. Refer back to [Lab 02](../../docs/PHASE-1-FREE-TIER/02-identity-provisioning-joiner.md) and [Lab 03](../../docs/PHASE-1-FREE-TIER/03-group-based-access-control.md) for step-by-step guidance
