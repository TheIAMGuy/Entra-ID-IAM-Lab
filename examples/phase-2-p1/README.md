# Phase 2 — Entra ID P1 Examples

Working examples from **Lab 04–06**: Privileged Access Management, Application Access Management, and Identity Lifecycle (Mover/Leaver).

## Files

- `pam-roles-example.json` — Privileged Access Management role assignments (Lab 04)
- `app-provisioning-example.json` — Enterprise application provisioning (Lab 05)
- `app-role-assignment-example.json` — User-to-app role assignments (Lab 05)
- `mover-leaver-workflow-example.json` — Identity lifecycle changes for Mover/Leaver (Lab 06)

## How to Use

1. Review the JSON structure for each example
2. Adapt principal IDs, group IDs, and application IDs to your environment
3. Use Microsoft Graph or the Entra ID admin center to import/recreate
4. Refer to the corresponding lab docs for detailed walkthrough
