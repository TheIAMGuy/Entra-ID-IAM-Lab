# Contributing to Entra-ID Cloud IAM Lab

Thanks for your interest in improving this enterprise IAM learning resource! This document outlines how you can contribute.

## How to Contribute

### Reporting Issues
- Found an error in the documentation or screenshots?
- Have a suggestion for improvement or additional scenarios?
- Noticed outdated Azure Portal UI?
- Create an issue describing the problem clearly.

### Improving Documentation
- Clarifications to existing steps or IAM concepts
- Additional screenshots or diagrams showing different scenarios
- Updates to reflect Azure Portal UI changes
- Corrections to IAM terminology or practices
- New scenarios (e.g., conditional access, multi-factor authentication)

### Adding Content
- Additional steps beyond the core JML lifecycle
- Advanced topics (device management, hybrid identity, etc.)
- Case studies or real-world application examples
- Integration scenarios (integrating with other identity systems)

### Submitting Changes
1. Fork the repository
2. Create a feature branch (`git checkout -b improvement/your-improvement`)
3. Make your changes
4. Commit with clear messages (`git commit -m "docs: clarify RBAC concepts in step 3"`)
5. Push to your branch (`git push origin improvement/your-improvement`)
6. Open a Pull Request with a description of your changes

## Guidelines

- **Documentation**: Use clear, professional language aligned with the existing style
- **Screenshots**: Keep consistent numbering (01, 02, etc.) and descriptive captions
- **IAM Concepts**: Ensure accuracy — this is an educational resource
- **Free Tier**: Respect the free-tier constraints and document workarounds
- **Enterprise Focus**: Maintain production-aligned practices and patterns
- **Markdown**: Use consistent formatting with headers, bullet points, and tables

## Content Standards

Each documentation file should include:
- **Clear objective** at the top
- **Step-by-step instructions** with context
- **IAM concepts** explaining the "why"
- **Screenshots** with numbered captions
- **Design rationale** or callouts where relevant

## Questions?

Feel free to open an issue if you have questions or need clarification on any part of the lab.

---

Thank you for contributing to better IAM education!
